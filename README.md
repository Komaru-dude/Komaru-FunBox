**Komaru-FunBox** — развлекательный и модерационный Telegram-бот с системой ролевых команд (RP) и различными командами для общения.

## Требования

* AMD64
* 512 мб свободной ОЗУ
* 1-2 гб свободного пространства
* Docker

## Настройка

Запустите команду для автоматической установки всех зависимостей и развертывания бота:

```bash
sudo bash -c "$(curl -sSL [https://github.com/Not-a-dude/Komaru-FunBox/raw/test/setup.sh](https://github.com/Not-a-dude/Komaru-FunBox/raw/test/setup.sh))"

## Вики

Бот так-же имеет [вики](https://Not-a-dude.github.io/Komaru-FunBox) рассказывающую о командах и настройке бота базированную на [docusaurus](https://docusaurus.io/)
