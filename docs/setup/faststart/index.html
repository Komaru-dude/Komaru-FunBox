🚀 Быстрый старт

📌 Как начать пользоваться ботом​

  1. Выдайте боту права администратора
    Это не обязательно, но очень рекомендуется — иначе вам придётся писать команды в виде /ai@komarufunbox_bot, а не просто /ai. Также без прав не будет работать модерация и часть функций.

    Минимальные права для корректной работы:

    • Удаление сообщений
    • Блокировка пользователей
    • Закрепление сообщений

  2. Назначьте себя администратором бота
    Создатель чата должен выполнить команду:

    /set_rank

⚙️ Команды бота​

🛠 Администрирование и модерация​

КомандаОписание
/set_rankНазначение прав (ранга) пользователю
/infoПолучение информации о пользователе
/historyИстория наказаний (варны, мьюты, баны)
/warnВыдать предупреждение
/muteМьют пользователя на время
/unmuteСнять мьют
/banЗабанить пользователя
/unbanРазбанить пользователя
/ban_mediaЗапрет медиа-функций для пользователя
/unban_mediaРазрешить медиа-функции
/enableВключить модуль
/disableВыключить модуль

🤖 Команды с ИИ​

КомандаОписание
/aiЗапрос к ИИ. Можно указать модель через -m, например /ai -m searchgpt
/agai"Злая" версия — отвечает с агрессией и матом. Поддержка моделей через -m
/chatНачать диалог с ИИ. Поддержка споров через -argue и моделей через -m
/chat_stopОстановить текущий ИИ-чат
/set_def_modelУстановить модель ИИ по умолчанию
/available_modelsСписок доступных ИИ моделей
/ocrРаспознать текст на картинке
/translateПеревод текста с указанием языка (/translate en Привет)

КомандаОписание

/videoСкачать видео (YouTube, TikTok и др.)

🧩 Модули​

Модули — это дополнительные функции, которые можно включать или выключать через команды /enable и /disable.

📋 Список доступных модулей​

МодульОписание
whoЕсли кто-то ответит «это что?» — бот спросит у нейросети и ответит
tagЛюбой участник сможет тегать всех через /tag и /tagall
autovideoАвтоматическая загрузка видео при отправке ссылки
warnВключает /warn
muteВключает /mute
banВключает /ban
senddisabledmsgПоказывает сообщение при попытке использовать отключённую функцию

👉 Пример включения модуля:

/enable who

👉 Пример отключения модуля:

/disable tag

ℹ️ Примечания​

  • ⚠️ Некоторые команды (например /update, /restart, /ban_media) доступны только персоналу.
  • 🧠 ИИ-команды используют OnlySQ API
  • 🔒 Команду /set_rank может использовать только создатель чата
  • 📆 Актуально на 13.05.2025
