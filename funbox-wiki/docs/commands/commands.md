# Команды

## 👋 Добро пожаловать

В этом разделе вы найдёте более исчерпывающие описания команд.
В панели слева вы найдёте подробное описание **каждой** существующей команды в боте

## 🤏 Краткое описание каждой команды

Ниже преведена таблица в которой кратко описана каждая команда/модуль существующий в боте

### Краткое описание

| Команда | Описание |
|---------|----------|
| `/start` | Базовая команда, выступает заглушкой |
| `/status` | Информация о времени работы бота |
| `/update` | Обновляет бота |
| `/restart` | Перезапускает бота |
| `/logs` | Отправляет логи |
| `/help` | Помощь по командам |
| `/cancel` | Отменяет текущее действие |
| `/new_year` | Время до нового года |
| `/birthdays` | Время до дня рождения кошек |
| `/weather` | Прогноз погоды |
| `/http_cat` | Рандомный кот с http.cat |
| `/http_dog` | Рандомная собака с http.dog |
| `/cat` | Отправляет рандомную фотку кота |
| `/cat_gif` | Отправляет рандомную гифку с котом |
| `/shutter` | Преобразует текст в залипания |
| `/available_models` | Выводит доступные модели |
| `/ai` | Бот сделает запрос к нейросети |
| `/agai` | "Злая" версия gemini |
| `/chat` | Начать чат с ИИ |
| `/chat_clear` | Очищает историю чата с ИИ |
| `/chat_stop` | Остановить чат с ИИ |
| `/set_def_model` | Устанавливает ИИ модель по умолчанию |
| `/image` | Бот сделает картинку |
| `/ocr` | Распознать текст с картинки |
| `/translate` | Бот переведёт текст |
| `/rp_setup` | Первично настроивает рп команды в вашем чате |
| `/rp_add` | Добавляет новую рп команду в ваш чат |
| `/rp_list` | Посмотреть список рп команд |
| `/rp_remove` | Удаляет существующую рп команду из вашего чата |
| `/rp_wipe` | Удаляет все рп команды в чате |
| `/video` | Скачать видео |
| `/gif` | Конвертирует видео в гифку |
| `/jpeg` | Шакализирует картинку |
| `/set_rank` | Устанавливает ранг |
| `/info` | Информация о пользователе |
| `/history` | История наказаний пользователя |
| `/warn` | Предупреждает пользователя |
| `/mute` | Мьютит пользователя |
| `/ban` | Банит пользователя |
| `/unmute` | Размьючивает пользователя |
| `/unban` | Разбанивает пользователя |
| `/enable` | Включить функцию в чате |
| `/disable` | Выключить функцию в чате |
| `/ban_media` | Блокирует часть функций пользователю |
| `/unban_media` | Разблокирует часть функций пользователю |
| `/reset_cooldown` | Сбрасывает кулдаун команд для пользователя |
| `/work` | Работа |
| `/steal` | Кража |
| `/rob` | Обокрасть пользователя |
| `/dice` | Казино |
| `/deposit` | Положить деньги на банковский счёт |
| `/withdraw` | Снять деньги с банковского счёта |
| `/top` | Показывает топ по балансу |
| `/set_name` | Меняет имя внутри бота |
| `/transfer` | Перевод между счетами |
