# 🤖 Основные

Вспомогательные команды, отвечающие за «подкапотную» работу системы и мониторинг.

---

## 🛰 Общие

Базовые инструменты, доступные всем пользователям.

### ⚡️ `/start`

Полотно полезного вводного текста о возможностях бота и краткая инструкция по началу работы.

**Синтаксис:**
` /start `

### 📊 `/status`

Техническая информация о текущем состоянии бота: Uptime, потребление RAM и задержка API Telegram.

**Синтаксис:**
` /status `

---

## 🛠 Администрирование

:::caution Доступ ограничен
Команды ниже требуют прав персонала бота.
:::

### 🔄 `/restart`

Мягкая перезагрузка процесса бота. Используется для применения мелких обновлений без изменения системных файлов.

**Синтаксис:**
` /restart `

### 🗑 `/update`

Принудительный сброс закэшированных данных и полная переинициализация всех модулей системы.

**Синтаксис:**
` /update `

### 📤 `/logs`

Отправка последних 50 строк логов файлом, старайтесь избегать исполнения этой команды в публичных чатах.

**Синтаксис:**
` /logs `
