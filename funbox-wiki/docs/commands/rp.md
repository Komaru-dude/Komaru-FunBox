# 🎭 Ролевые команды (RP)

Система Role Play (RP) позволяет участникам групп взаимодействовать друг с другом через текстовые действия. С её помощью можно создавать уникальную атмосферу в чате, используя как стандартные, так и пользовательские команды.

:::caution Доступ ограничен
Команды управления и настройки (`/rp_setup`, `/rp_add`, `/rp_remove`, `/rp_wipe`) требуют наличия прав модератора или администратора в боте.
:::

---

## 📋 Управление списком команд

Эти команды позволяют просматривать доступные действия или возвращать настройки к исходному состоянию.

### /rp_list

Выводит полный список всех RP-команд, доступных в текущем чате, вместе с их описанием.
**Синтаксис:** `/rp_list`

:::info
Команда имеет кулдаун **5 секунд**. Доступна только в группах и супергруппах.
:::

### /rp_setup

Сбрасывает текущий набор команд и устанавливает базовый список RP-действий по умолчанию.
**Синтаксис:** `/rp_setup`

* **Как это работает**: После ввода команды бот предложит подтвердить действие кнопками "Да" или "Нет".
* **Важно**: Это действие удалит все ваши созданные вручную команды.

---

## 🛠 Создание собственных действий

Вы можете расширить функционал бота, добавив свои уникальные команды через интерактивный конструктор.

### /rp_add

Запускает процесс создания новой команды. Бот проведет вас через три этапа:
**Синтаксис:** `/rp_add`

| Этап | Описание | Ограничения |
|---|---|---|
| **1. Название** | Имя команды без символа `/`. | До 20 символов. |
| **2. Описание** | Краткое пояснение, что делает команда. | До 50 символов. |
| **3. Сообщения** | Варианты текста, которые бот выведет в чат. | До 4 вариантов. |

:::tip Использование переменных
При настройке сообщений используйте специальные плейсхолдеры:

* `{user1}` — Имя того, кто использовал команду.
* `{user2}` — Имя пользователя, на чье сообщение ответили.

**Пример:** `{user1} угостил чаем {user2} | {user1} налил кружку кофе для {user2}`
:::

### /rp_remove

Удаляет выбранную RP-команду из памяти чата.
**Синтаксис:** `/rp_remove [название]`

**Пример:** `/rp_remove обнять`

### /rp_wipe

Полностью очищает список команд, удаляя даже базовые настройки.
**Синтаксис:** `/rp_wipe`

:::info
У команды установлен кулдаун **5 минут**, чтобы предотвратить случайную очистку данных.
:::

---

## 🕹 Как использовать в чате

Чтобы применить действие к другому пользователю:

1. **Ответьте (Reply)** на сообщение нужного человека.
2. Введите вашу команду со слешем, например: `/обнять`.
3. Бот выберет один из случайных вариантов текста, настроенных для этой команды, и опубликует его.

:::caution Ограничения

* RP-команды работают только в **группах и супергруппах**. В личных сообщениях или каналах они недоступны.
* Для отмены процесса создания команды (`/rp_add`) на любом этапе введите `/cancel`.
:::
