# 🚀 Быстрый старт

## 📌 Как начать пользоваться ботом

1. **Выдайте боту права администратора**  
   Это **не обязательно**, но **очень рекомендуется** — иначе вам придётся писать команды в виде `/ai@komarufunbox_bot`, а не просто `/ai`. Также без прав не будет работать модерация и часть функций.

   Для некоторых функций в боте требуюся дополнительные права:
   - Удаление сообщений для работы функции auto_delete
   - Блокировка пользователей для работы функций модерации

2. **Права**  
   Назначьте **себя** и ваш персонал на роли в боте, учитывайте, что команду использовать может только создатель или назначенный вами администратор:

   ``` telegram
   /set_rank
   ```

---

## 🧩 Настройки

Здесь вы можете легко и быстро адаптировать бота под себя — изменить параметры и поведение так, чтобы он работал именно так, как вам удобно.

Для начала работы введите команду:

``` telegram
/settings
```

---

## ℹ️ Примечания

- ⚠️ Некоторые команды (например `/update`, `/restart`, `/ban_media`) доступны **только персоналу**.
- 🧠 ИИ-команды используют [OnlySQ API](https://api.onlysq.ru/)
- 🔒 Команду `/set_rank` может использовать только **создатель чата**
- 📆 Актуально на **21.07.2025**
