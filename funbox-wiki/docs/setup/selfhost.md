# 🛠️ Самохостинг

В этой статье вы узнаете, как запустить бота на собственной машине.

---

## 📋 Системные требования

Для запуска бота потребуется:

- 🐍 **Python** версии **3.9** или новее  
- 🐧 **Linux** (желательно Debian/Ubuntu, но подойдёт и другой дистрибутив)
- 🛠️ **Systemd** (необязателен, но **настоятельно рекомендуется** для автозапуска и управления процессом)

---

## ⚙️ Быстрая установка

Вы можете воспользоваться автоматическим установочным скриптом, который скачает зависимости, настроит окружение и запустит бота:

```bash
sudo bash -c "$(curl -sSL https://github.com/Not-a-dude/Komaru-FunBox/raw/test/setup.sh)"
```

Скрипт выполнит все необходимые действия и сразу запустит бота.

---

## 1️⃣ Ограничение работы в выбранных чатах

Если вы хотите, чтобы бот работал **только в определённых чатах** (например, в вашем личном или в группе), выполните следующие шаги:

1. Включите режим работы в ограниченных чатах, установив переменную:

```env
SPECIFIC_CHAT=true
```

2. Укажите список **ID разрешённых чатов**, разделяя их запятыми. Получить ID можно с помощью бота [@getmyid_bot](https://t.me/getmyid_bot):

```env
SPECIFIC_CHATS_ID=123456789,987654321
```

Теперь бот будет отвечать **только** в указанных чатах, игнорируя все остальные.
