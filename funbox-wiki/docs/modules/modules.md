# Модули

## 👋 Добро пожаловать

В этом разделе вы найдёте более исчерпывающие описания модулей.
В панели слева вы найдёте подробное описание **каждого** существующего модуля в боте

### Краткое описание

| Модуль | Описание |
|--------|----------|
| `who` | Написали "это что?" - бот спросит нейросеть и ответит |
| `tagall` | Даёт доступ обычным людям упоминать всех через `/tagall` |
| `autovideo` | Автоматическая загрузка видео |
| `warn` | Позволяет предупреждать пользователей |
| `mute` | Позволяет мьютить пользователей |
| `ban` | Позволяет банить пользователей |
| `senddisabledmsg` | При включении отправляет сообщение для отключённых функций |
| `alo` | ??? |
| `economy` | Включает и выключает экономику в вашем чате |
| `sendcooldown` | Отправляет сообщения о кулдауне если включено |
| `auto_delete` | Автоматически удаляет некоторые сообщения |
| `auto_eg_free` | Каждый четверг отправляет бесплатные игры в egs |
